04 / AI & LANGUAGE

Evaluating AI responses.
Respecting language and context.

Examples below are independently written demonstrations, not reproductions of confidential project material or official Outlier scoring guidance.

FICTIONAL PROMPT

“Write a polite two-sentence reply to a customer asking how to reset a forgotten password. Do not claim to reset it for them.”

RESPONSE AA

“Your password has been reset. Please log in again now.”

Misses instruction
RESPONSE BB

“You can reset your password using the ‘Forgot password?’ link on the sign-in page. Follow the instructions sent to your registered email address, and let us know if you need further help.”

Stronger fit for this prompt
↳
Sample evaluation rationale

Response B is the stronger demonstration because it offers an actionable next step without falsely claiming that the password has already been changed. It follows the prompt more closely and provides a helpful continuation. This judgment uses illustrative criteria only.

FICTIONAL PROMPT

“Explain to a new user, in plain language, what two-factor authentication does.”

ILLUSTRATIVE CRITERIONRESPONSE ARESPONSE B
RelevanceRelevantRelevant
ClarityUses technical wordingUses plain language

Sample evaluation rationale

Response B would be preferred under these demonstration criteria because it explains the purpose in accessible language and covers both parts of the sign-in process. Actual evaluation projects use the criteria and weighting specified in their own instructions.
