# Photography assets

The gallery is designed for Almira's own hiking and photography images. Add files here using these names, or change the `data-image` values in `index.html`:

- `hiking-trail.jpg`
- `landscape.jpg`
- `nature-detail.jpg`

Use photographs you own or have permission to publish. Consider resizing images to around 1600px on the longest edge and compressing them for faster page loads. Add accurate alt text in the relevant `data-alt` attribute in `index.html`.

Until images are added, the portfolio displays designed placeholder tiles. Clicking a placeholder explains that the image file needs to be added.
